# WildOS Memory Ring - World Editor guide

Base level already contains: terrain, the asphalt ring road (DecalRoad),
a dirt spur and the spawn point. All props/materials below are bundled in
this mod and resolve on load - place them yourself with the World Editor.

## Bundled prop meshes (pick via World Editor -> Objects / Static)

levels/wildos_memory_ring/art/shapes/props/cabin2.dae

## Materials
All materials are defined in art/shapes/main.materials.json and are bound
to bundled real textures, so nothing shows as NO MATERIAL.

## Notes
- Houses: house1..house4, house_small1..3, cabin1..2
- Trees: tree_beech_*, tree_oak_*, tree_aspen_*, pine_radiata_*
- Guardrail: guardrail2.dae (lay along the road edge)
- Street light: pole_city1.dae
- Utility pole: electric_pole_wood_old_01.dae
- Road sign: bussign.dae
- Bush: generibush.dae / sidewalk_brittlebush1.dae
