3. 已有候选生成中，显式视觉目标遇到背离目标超过90度的图出口或无候选时，先尝试8米内的前向点及左右2米偏移。复用现有运动学朝向、Smac、实际车体/双地图校验与失败缓存；失败后保留原图候选，不增加任务状态机。
