# 真实车体 LiDAR 覆盖修复（2026-10-11）

## 故障链与证据边界

pilot4 在约 159.718 秒停滞处，真实静态结构与两张发布代价地图不一致。旧挂载配置为 3.6m、`dir=[0,-1,-0.45]`、360°、16/60°/40m。车辆暂停重建该姿态，旧传感器和新建同参数挂载传感器对附近结构均为 0 回波；恢复物理、保持制动后仍为 0。不是历史原始扫描或历史精确车体变形重放，不能据此证明所有停滞都由物理接触造成。

同位置/方向的临时静态传感器可产生约 1200 回波；车辆在场且 `vehicle` 参数有/无均可。故简单的车体遮挡、旧传感器失效，以及下游过滤作为本次漏观测首因均缺少支持。SDK 的“360° 模式下方向无意义”说明与本实例实际输出不一致，不能再以该说明假设下倾方向无影响。

挂载参数控制：仅改水平方向，保持 3.6m，高处结构回波 75，限流后 39、障碍标记后 5；仅增至 90° 或仅降至 1.7m、仍下倾，均为 0。改为 1.7m+水平后 1695 回波、限流后 674、标记后 33。四个诊断航向（0/+90/180/-90°）中该配置回波分别 1700/1401/967/496，四象限均有观测。诊断过程中有明确记录的姿态重建/恢复，不是自主搜寻或原地转向能力证明。航向脚本继承的 scope 字段误写“两次”，按归档脚本实际调用为初始1次、四航向4次、恢复1次，共6次；保留原字段并在此更正。

实际安装 Nav2 的隔离重放：输入上述 1.7m+水平标记/清除点，31个静态采样点中13个 cost=100、其余99、无自由格。3.6m+水平的相同采样点虽然无自由格，均未直接落到 lethal，近场标记明显更稀疏。选择车顶附近常规高度用于近场覆盖，未改高度过滤、地面拟合、车体足迹、转弯半径或速度。

**隔离诊断程序退出失败仍保留**：安装的 `nav2_costmap_2d` 独立进程完成生命周期清理后 SIGINT 退出码 -11（早期尝试 -6），地图观察结果与进程清理结果分别记录。此诊断退出问题未修复，不把它当成生产规划进程崩溃的证明，也不宣称所有验证都通过。
