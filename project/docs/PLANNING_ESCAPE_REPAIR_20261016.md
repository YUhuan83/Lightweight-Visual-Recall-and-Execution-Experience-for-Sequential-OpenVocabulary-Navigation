## 本轮实现的局部恢复候选

变更仅3个既有文件：graph_path_bridge.py、execution_recovery.py、相关routing测试。冻结436成员 `3fe6f21557bf25408de7668f895bc53b55a56608992ef02e4d8b86d305069b14`，`deploy/20261016_planning_escape_candidate/`。C++、视觉评分、模型、到达、速度、半径及碰撞约束不改。

- 至少两个不同探索交易在60秒内、同一2米位置范围内耗尽候选且全部为empty_path，才考虑局部恢复。重复同一目标不累计不同目标计数。失败不是静态障碍训练标签。
- 要求Ackermann、已允许执行、没有活动/待定/隔离动作、对象/记忆/查询重置状态不占有执行，里程计及两张地图和传输健康新鲜，车辆低速。
- 仅从近期真实前向驾驶记录拟合2–4米倒车弧，保持原60秒/96点上限、曲率和走廊约束。同一位置3米内不重复尝试。没有合格记录则继续原失败流程，不生成猜测退路。
- 恢复复用原 send_motion_segment 的实际姿态、全局完整路径、局部足迹、曲率、控制器及取消保护；记录地图不能替代实时地图检查。
