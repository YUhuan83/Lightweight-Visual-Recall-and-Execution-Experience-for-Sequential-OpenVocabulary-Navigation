# 视觉意图与物理恢复交接修复

## 最早违约点与约束

视觉临时目标的激活、完成、放弃均使用通用reset，重置的不只是语义路线，还包括实测行驶走廊、失败位置/时间及恢复意图。过期视觉计时器可在旧动作取消待停稳时删除恢复意图。与清理事务预算是两个独立缺口。

本次区分三类状态：

| 状态 | 生命周期与交接 |
| --- | --- |
| 实测物理历史 | 同一查询内视觉目标切换保留原位置与时间；不补采样、不延长60秒有效期；保持原尝试位置限制 |
| 已准备或执行的脱困 | 视觉激活/放弃等待；不转移旧epoch权限，不把旧路径当预验证动作；仍须旧动作终态、持续实测停稳、当前地图及传输检查 |
| 新查询、实例/任务撤销 | 仍走原reset，撤销旧恢复意图；不能因历史保留跨查询恢复旧动作 |

## 实现与影响

- `execution_recovery.py::execution_recovery_owns_motion`统一表示执行中、等待停稳的执行恢复、等待输入的规划恢复。
- `visible_approach.py`在激活和放弃前检查该归属，防止视觉定时器/新hint抢占独立物理恢复。
- 三处视觉交接调用现有 `reset(preserve_execution_corridor=True)`，保留物理历史；未直接恢复带旧epoch的deferred_execution_escape。活动意图通过先等待的方式保留原归属。
- 恢复完成后保护自然解除，过期视觉目标仍会释放；新query仍可直接撤销。不是永久锁住视觉目标，也没有延长观测新鲜度或动作寿命。
- 没有修改物理、碰撞、速度、地图阈值和取消/停稳保护。未修全部目标确认交接或传感器重启/位姿跳变，相关风险仍需共同验收。
