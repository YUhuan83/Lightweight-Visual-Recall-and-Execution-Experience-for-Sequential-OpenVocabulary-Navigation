- `ackermann_smac/src/planner.cpp`：在既有候选数量和总时限内保留可行完整路线，以完整路径长度 + 每次换向 3m 等效代价排序；同分保持原先顺序。首次搜索仍按原 .01s 余量准入，有可行路线后的额外搜索预留 .05s 给最终复核，不修改 native 1.5s / total 2s / connector .2s 配置。
