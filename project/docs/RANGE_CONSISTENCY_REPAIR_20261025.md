## 实现及契约

运行增量只有2个文件，未改变v28规划、物理、控制或记忆实现。

1. `localization_geometry.foreground_depth/_surface_quality`：保留逐像素去重、8点、表面二维分布、深度分簇、置信度及歧义拒绝。代表位置改为距稳健中位中心最近的**当前支持回波**，不组合一个未测量位置。存在近期参考时，可选离它最近且距离不超过1.5米的当前支持回波；没有相近实测点就重新使用当前表面的代表点。歧义表面仍拒绝，不因参考存在而选定近表面。
2. `ObjectMaskTriangulator`：保存至多一个世界坐标LiDAR参考位置和采集戳。只由本次通过原深度门的LiDAR更新；转换到当前相机采集坐标后用于上述代表点选择。相邻观测间隔超过原5秒则不使用；query切换或深度歧义清除。空扫描、重复帧、bearing-only和multiview不刷新参考，不重发旧位置。此参考用于代表点连续性，不是新增地图或确认缓存。
3. `triangulate_bearings`：位置仍为原非加权最小二乘解。每条射线的横向误差预算为 `max(0.1m, depth*tan(angular_tolerance), residual)`，通过同一求解器传播：`A^-1 [sum(sigma_i^2 P_i)] A^-T`，其中 `P_i=I-r_i r_i^T`、`A=sum(P_i)`。水平半径仍不得超过原3米。角误差预算是既有配置的保守传播，尚未标定为真实统计置信区间。
4. 初版曾使用逆加权精度描述仍为非加权的位置解；新增独立微角度扰动回归复现约8%元素偏差，r2改为上述同估计器传播后通过。初版已冻结，不覆写其现场证据，也不把初版现场当r2验收。
