# 弱观察点准入与实际车辆规划（2026-10-26）

目标仍是完整、流畅搜寻；本记录不能替代完整到达验收。v37/v40及用户主代码保留。候选位于test_artifacts/general_observation_20261026/candidate，服务器独立v41_general_observation，不commit、不推广。

## 两遍复核的原因

1. 已接纳的弱观察点在车辆运动后不满足单条前向圆弧，prepare_visible_vehicle_goal便可能直接release_visible_approach并报no_vehicle_path，未让Smac判断一般车辆路径。这只证明该条圆弧不存在，不证明车辆无路可走。
2. 原局部fallback在无GraphNav候选时把终点航向重算为直线bearing，丢掉圆弧终点navigation_heading。正常候选路径有圆弧航向优先逻辑，fallback没有，是两个分支的接口差异。

v40真实快照，按事件replay_inputs里的精确odom_stamp取车姿，用此前已发布的raw全局图，实际12米Smac逐点逐航向各两遍：

| 快照 | 单圆弧半径 | 原生规划结果，两遍一致 |
|---|---:|---|
| 83.326s，fallback | 50.978m | 三种yaw均可规划，均1次换向；不能声称航向修复使此例更快 |
| 89.070s，no_vehicle_path | 288.863m | 三种yaw均失败，不能归因单圆弧检查 |
| 99.743s，no_vehicle_path | 23.290m | 三种yaw均失败，不能归因单圆弧检查 |
| 99.907s，no_vehicle_path | 11.977m | 单圆弧检查拒绝，但Smac可规划；bearing/保持起始yaw为1次换向，圆弧推算yaw为2次 |

上述为公开raw图上的规划对照，非现场私有锁定图精确回放，也未证明全前向到达。第三个无路快照的“完全不可达”推断被反例否定，另两个仍失败；没有把所有无路都归因航向。证据observation_heading_20261026/weak_admission_probe与weak_admission_summary.json。

## 最小成组修改与边界

- 对**已经接纳**的弱观察任务，优先尝试原有新鲜、合适的前向提示刷新；否则单圆弧不成立但旧点仍在当前车头前方、距离仍2–10米且bearing终态车身pose通过地图检查时，允许进入正常Smac规划。记录visible_target_general_plan，不直接发控制、不生成到达证据。
- 新提示激活仍用原几何/新鲜度门；已在车后或被地图阻挡的旧点仍释放。旧点只是有界导航意图，不变成新鲜视觉证据；原30秒任务上限、query/实例归属、异步规划代际、物理停稳/ACK、完整车身及两张图、12米Smac/8米控制曲率全部保留。
- fallback有有效圆弧航向时使用该航向；无单圆弧时保留正常bearing交给规划器判断；旧理想/无navigation_heading消息保持原行为。没有允许原地旋转、关闭碰撞或放宽可靠定位/车身2米到达门。
- 风险：一般规划可能接纳需要换向的路径，从而增加换挡或规划消耗，必须结合真实搜索与停顿验证；不得因新增反例通过便覆盖v40。
